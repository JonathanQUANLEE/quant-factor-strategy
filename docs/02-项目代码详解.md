# 项目代码详解

> 逐文件讲解代码怎么写的、为什么这么写。适合对照源码学习。

## 整体架构

```
main.py  ──调用──▶  data.py     拿到干净的价格矩阵
   │                    │
   │                    ▼
   │              factors.py   算因子 + IC分析
   │                    │
   │                    ▼
   └──────调用──▶  backtest.py  模拟交易 → 日收益序列
                        │
                        ▼
                  metrics.py   收益序列 → 绩效指标
```

数据流全程是 **pandas.DataFrame**：
- 价格矩阵：`index=日期, columns=股票代码, values=收盘价`
- 因子矩阵：同样结构，values 是 0-1 的排名分
- 日收益：`index=日期, values=当日组合收益`

## data.py — 数据层

### 对外接口

```python
load_data()   # 统一入口：真实数据优先，失败降级合成数据
clean_data()  # 清洗：剔除问题股票、修价格、防前视
```

### 关键设计 1：为什么要有合成数据降级？

yfinance 在国内网络下经常超时/限流。如果一失败整个项目就跑不了，这在工程上是不可接受的。所以：

```python
real = fetch_real_data(...)      # 先试真实数据
if real is not None:
    return real, "real"
return generate_synthetic_data(), "synthetic"   # 失败就降级
```

**面试话术**："数据源做了容错设计，真实接口失败时降级到合成数据，保证研究 pipeline 不中断；同时合成数据注入了可解释的因子结构，可以用来做策略逻辑的回归验证。"

### 关键设计 2：合成数据不是随机噪声

```python
persistence = rng.uniform(-0.10, 0.50, n_stocks)  # 趋势持续性
momentum_edge = ... - (idio_vol - idio_vol.mean()) * 0.06  # 低波动异象
```

- `persistence > 0` 的股票：昨天涨今天继续涨（动量结构）
- `persistence < 0` 的股票：昨天涨今天跌（反转结构）
- 高波动股票给负漂移（低波动异象）

这样因子回测出来**方向是可解释的**：动量因子 IC 应该为正。如果算出来是负的，说明代码有 bug——这就是"合成数据做逻辑回归测试"的价值。

### 关键设计 3：清洗里的两个保命操作

```python
# ① 绝不 fillna(0)
close = close.where(close > 0).ffill()   # ✅ 错误价格置NaN再前向填充
# close.fillna(0)                        # ❌ 价格为0 → pct_change = -100% → 回撤-99%

# ② 绝不 bfill
close = close.dropna(how="any")          # ✅ 开头缺数据的行直接删
# close.bfill()                          # ❌ 用明天的价格填昨天 → 前视偏差
```

> 这两个坑是我实际踩过的：第一版回测回撤算出 -99%、年化 10000%，排查半天发现是价格被置零。

## factors.py — 因子层

### 三个因子的统一模式

```python
def momentum_factor(close, window=20):
    ret = close.pct_change(window)      # 过去20日收益
    return _cross_sectional_rank(ret)   # 当天在所有股票里排名 → 0~1
```

所有因子输出**方向统一为"越大越看好"**：
- 动量：涨幅大 → 排名高 → 看好 ✅
- 低波动：波动小 → `1 - 波动排名` → 看好 ✅
- 反转：近期跌 → `1 - 涨幅排名` → 看好 ✅

**为什么用 rank 不用 z-score？**
金融数据重尾（偶尔涨跌 10%+），z-score 会被离群值拉偏；rank 天然有界 [0,1]，多因子加权时量纲统一。

### IC 计算的核心三行

```python
def ic_series(factors, forward_returns):
    aligned_f = factors.shift(1)   # ① 因子用昨天的，防前视
    ...
    ics.append(f.corr(r, method="spearman"))  # ② 秩相关，抗离群值
```

`factor_report()` 汇总成 IC 均值 / ICIR / IC>0 占比，直接指导权重分配。

### 多因子合成

```python
def composite_score(close, weights):
    # 权重和必须为1，断言防手滑
    assert abs(sum(weights.values()) - 1.0) < 1e-9
    return sum(weights[name] * f for name, f in factors.items())
```

权重是**策略的自由参数**，本项目按 IC 证据定：`{"momentum": 0.45, "lowvol": 0.40, "reversal": 0.15}`（反转 IC 为负 → 降权）。

## backtest.py — 回测引擎（核心）

### 为什么自己写而不是用 Backtrader？

1. **可控**：成本模型、调仓时点、持仓权重全部透明，面试能逐行讲
2. **轻量**：不依赖框架版本，逻辑错了容易定位
3. **学习价值**：写一遍胜过调十次库

### 回测主流程

```python
# 1. 只在调仓日生成目标权重，其余日为 NaN
weights_arr = np.full((n_days, n_stocks), np.nan)

for idx in rebal_indices:                    # 每20天一个调仓日
    row = score.iloc[idx].dropna()
    selected = row.nlargest(top_n).index     # 选分数前5
    target[sel] = (1 - cash_buffer) / 5      # 等权 + 5%现金缓冲
    
    turnover = |新权重 - 旧权重| / 2          # 换手率
    costs[idx] = turnover * cost * 2         # 双边成本
    prev_target = target

# 2. ffill 让调仓日之间的持仓保持不变（"买入并持有"到下次调仓）
weights = pd.DataFrame(weights_arr).ffill().fillna(0)

# 3. 组合日收益 = Σ(权重 × 个股日收益) - 成本
net = (w * r).sum(axis=1) - costs
```

### 三个容易写错的地方

| 地方 | 错误写法 | 正确写法 |
|------|---------|---------|
| 换手成本 | 每天都扣 | 只在调仓日扣 |
| 换手率 | `sum(差值)` | `sum(差值)/2`（买卖各算一次，除2才是单边） |
| 持仓延续 | 自己写 for 循环传递 | `ffill()` 一行搞定且不易错 |

### 基准的坑

```python
benchmark = buy_and_hold(close)        # 返回的是【净值曲线】
benchmark_daily = benchmark.pct_change()  # performance_summary 要的是【日收益】
```

> 第二版踩的坑：把净值当日收益再 cumprod 一次 = 双重复利，基准年化算出 10^76 %。

## metrics.py — 指标层

每个函数都是纯函数（输入收益 → 输出指标），方便单独测试：

```python
sharpe_ratio(daily_returns)    # (年化收益 - 无风险利率) / 年化波动率
max_drawdown(nav)              # min(nav / cummax(nav)) - 1
calmar_ratio(daily_returns)    # 年化收益 / |最大回撤|
performance_summary(...)       # 一键汇总成 DataFrame
```

**年化为什么用几何年化？**
`(末值/初值)^(252/天数) - 1` 而不是 `mean*252`——前者是复利口径，长周期下两者差异巨大。

## 改参数实验（加深理解）

在 `main.py` 里改这些，观察指标变化：

| 实验 | 改哪里 | 预期现象 |
|------|--------|---------|
| 提高调仓频率 | `rebalance_days=20 → 5` | 换手率↑、成本↑、收益可能↓ |
| 持仓更分散 | `top_n=5 → 20` | 波动↓、收益向基准靠拢 |
| 关掉成本 | `cost_per_side=0.001 → 0` | 收益虚高——体会成本的重要性 |
| 去掉一个因子 | 权重改 `{"momentum":1.0,...}` | 看单因子的独立贡献 |
