# 使用指南

## 环境要求

- Python 3.10+
- 依赖见 `requirements.txt`

## 安装

```bash
git clone https://github.com/JonathanQUANLEE/quant-factor-strategy.git
cd quant-factor-strategy

# 建议用虚拟环境
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
```

## 运行

```bash
python main.py
```

预期输出 8 个 STEP，最终生成：

```
output/
├── backtest_report.png     # 四联图：净值/回撤/月度热力/换手率
├── performance_summary.csv # 绩效指标表
└── nav_curve.csv           # 策略与基准的日净值
```

## 数据源说明

### 默认行为
1. **先尝试 yfinance 拉真实行情**（A股代码如 `600519.SS`）
2. 网络不通/被限流时**自动降级为合成数据**，打印提示：

```
[data] 真实行情获取失败（网络限流/不可达），降级为合成数据
数据来源: synthetic
```

> ⚠️ 合成数据上的回测结果**仅验证框架逻辑**，不代表真实市场收益。

### 如何确保用真实数据

yfinance 需要能访问 Yahoo Finance（国内可能需代理）。验证方式：看运行日志第一段 `数据来源: real` 即为真实数据。

也可以换其他数据源，只需在 `data.py` 的 `load_data()` 里接入，保证返回结构一致：

```python
{
    "close":  DataFrame(index=日期, columns=股票, values=收盘价),
    "volume": 同结构,
    "high":   同结构,
    "low":    同结构,
}
```

推荐的 A 股数据源：`baostock`（免费）、`akshare`（免费）、`tushare`（积分制）。

## 添加自己的因子

在 `factors.py` 里照这个模板写：

```python
def my_factor(close: pd.DataFrame, window: int = 10) -> pd.DataFrame:
    """我的因子：xxx 逻辑"""
    raw = close.pct_change(window)        # ① 算原始值
    return _cross_sectional_rank(raw)     # ② 截面排名，方向统一越大越好
```

然后三步接入：
1. 在 `composite_score()` 的 `factors` 字典里加一项
2. 分配权重（和为1）
3. 在 `main.py` 的 STEP 3 加进 `factor_values`，看它的 IC 再决定权重

## 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 中文输出乱码 | Windows 控制台 GBK | main.py 开头已强制 UTF-8；或设置 `chcp 65001` |
| `数据来源: synthetic` | yfinance 网络不通 | 配置代理，或接受合成数据跑通流程 |
| pip 安装 numpy 警告 | 环境里有旧版编译包 | 一般可忽略；必要时 `pip install -U numpy` |
| 回撤 -99% / 年化 10000% | 价格含 0 或负值 | 检查数据清洗，**绝不 fillna(0)** |
| 基准年化大得离谱 | 净值被当收益重复 cumprod | benchmark 先 `pct_change()` 再传入 |
