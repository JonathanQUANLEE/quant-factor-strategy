# 量化交易入门基础

> 本文是项目的学习前置知识。读完再看代码，事半功倍。

## 1. 量化交易是什么？

**量化交易 = 用数据和数学模型代替人的主观判断来做买卖决策。**

传统交易：老王看新闻感觉要涨 → 买入
量化交易：模型计算出"这类特征的股票未来大概率涨" → 按规则买入

核心区别不是"用不用电脑"，而是**决策必须可被数据验证**。一个策略说"我觉得会涨"没用，必须能回答："过去 10 年这样操作，赚了多少？最惨亏多少？承担了多少风险？"

## 2. 什么是因子（Factor）？

**因子 = 能够解释或预测股票收益的变量。**

| 因子 | 计算方式 | 背后的逻辑 |
|------|---------|-----------|
| 动量因子 | 过去 20 日涨幅 | 涨得好的短期继续涨（趋势延续） |
| 低波动因子 | 过去 20 日波动率 | 波动小的股票风险调整后收益反而好 |
| 估值因子 | 市盈率 PE | 便宜的股票长期回报更高 |
| 规模因子 | 市值 | 小盘股跑赢大盘股 |

**多因子选股**：给每只股票算多个因子 → 合成一个综合分 → 买分数最高的几只。

本项目用的三个因子在 `factors.py`，每个因子都做了**截面排名**（在所有股票里排第几百分位），这样不同量纲的因子才能加权合成。

## 3. 什么是 IC？为什么它是因子的"体检报告"？

**IC（Information Coefficient）= 因子值与未来收益的相关系数。**

```
每天算一次：今天因子排名 vs 未来5天收益排名 的 Spearman 秩相关
然后看这段时间 IC 的均值和稳定性
```

**怎么读 IC：**

| 指标 | 含义 | 参考标准 |
|------|------|---------|
| IC 均值 | 因子预测方向和强度 | > 0.03 可用，> 0 为正向预测 |
| IC 标准差 | 稳定性 | 越小越稳 |
| ICIR | IC均值/IC标准差 | > 0.3 不错 |
| IC>0 占比 | 胜率 | > 55% 及格 |

**本项目实例**：动量因子 IC=0.027（可用），反转因子 IC=-0.016（方向反了）→ 所以合成时把反转权重从 0.3 降到 0.15。**这就是 IC 分析指导实践。**

## 4. 什么是回测（Backtest）？

**回测 = 拿历史数据假装"如果当年这么做，结果会怎样"。**

流程：
```
历史行情 → 每天按策略算信号 → 模拟买卖 → 扣除手续费 → 
统计总收益、波动、回撤 → 和"什么都不做"的基准对比
```

### 回测最常见的三种"自欺欺人"（面试必问）

| 假象 | 解释 | 本项目怎么防 |
|------|------|-------------|
| **前视偏差** | 用了未来数据。比如今天收盘后才知道今天的新闻，但回测里用"今天的新闻"决定"今天开盘买" | IC 计算时因子 `shift(1)`；调仓只用当天及之前的数据 |
| **幸存者偏差** | 只拿现在还活着的股票回测，退市的没算 → 收益虚高 | 真实数据接入后需用含退市股的全成分数据 |
| **过拟合** | 参数调到历史最优，但未来不灵 | 项目留了 walk-forward 扩展点（见 README） |

### 交易成本不能不扣

真实交易有佣金 + 滑点。不扣成本的回测 = 纸上富贵。本项目按**单边 0.1%** 扣除，调仓时按换手率计算总成本。

## 5. 核心绩效指标怎么读？

| 指标 | 一句话解释 | 怎么判断 |
|------|-----------|---------|
| **年化收益率** | 平均一年赚多少 | 和基准比，高才有价值 |
| **年化波动率** | 收益上下晃动的幅度 | 越低越稳，但太低可能没赚钱 |
| **夏普比率** | 每承担 1 份波动，赚几份超额收益 | <0 亏钱；0-1 一般；1-2 不错；>2 警惕过拟合 |
| **最大回撤** | 历史上最惨从高点跌多少 | <10% 优秀；<20% 可接受 |
| **卡玛比率** | 年化收益 ÷ 最大回撤 | >1 健康 |
| **信息比率** | 超额收益的稳定性 | 比夏普更严格，因为它只看跑赢基准的部分 |

**为什么夏普和回撤要一起看？**
夏普惩罚"天天晃"，回撤惩罚"一次跌惨"。一个策略可以夏普不错但回撤大（平时稳、某次暴跌），必须两个都看。

## 6. 本项目的策略逻辑（一图流）

```
40只股票的行情数据
    │
    ▼
┌─────────────────────────────┐
│ 三个因子（各算一个0-1的排名）  │
│  动量: 过去20日涨幅排名        │
│  低波动: 波动率排名取反        │
│  反转: 过去5日涨幅排名取反      │
└─────────────────────────────┘
    │
    ▼ IC分析：发现反转因子IC为负 → 降权
    │
    ▼
综合分 = 0.45×动量 + 0.40×低波动 + 0.15×反转
    │
    ▼ 每20个交易日
选综合分前5名 → 等权买入 → 扣0.1%成本 → 持有20天 → 换仓
    │
    ▼
绩效: 年化26.68% 夏普1.59 回撤-12.34% 超额+14.39%
```

## 7. 名词速查表

| 名词 | 解释 |
|------|------|
| Alpha | 能带来超额收益的预测信号，量化圈说"挖因子"就是"挖 Alpha" |
| 多头策略 | 只买不卖空，赚上涨的钱 |
| 调仓 | 买卖股票更新持仓，本项目每 20 交易日一次 |
| 换手率 | 一次调仓买卖的总量占持仓比例，越高成本越高 |
| 截面 | 同一天所有股票横着比（vs 时间序列竖着看） |
| 基准 | 对照组，本项目用"等权买入所有股票" |
| 无风险利率 | 国债收益率，夏普公式的减项，本项目取 2% |
| 过拟合 | 策略把历史噪声当规律，样本外失效 |
