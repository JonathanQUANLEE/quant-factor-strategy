## 策略逻辑

1. **三因子打分**（每日截面百分位排名，方向统一为"越大越看好"）：
   - 动量因子：过去 20 日收益率排名（趋势延续）
   - 低波动因子：过去 20 日波动率排名取反（低波动异象）
   - 短期反转因子：过去 5 日收益率排名取反（超涨回调）
2. **IC 分析验证**：逐日计算因子与次期收益的 Spearman 秩相关，用 IC/ICIR 判断因子有效性，**依据 IC 证据分配权重**（IC 为负的因子降权）
3. **综合打分**：`score = 0.45×momentum + 0.40×lowvol + 0.15×reversal`
4. **回测**：每 20 个交易日调仓，持有打分前 5 的股票（等权 + 5% 现金缓冲），单边交易成本 0.1%
5. **绩效评估**：年化收益、夏普比率、最大回撤、卡玛比率、信息比率 vs 等权基准

## 关键工程决策（面试可展开）

| 决策 | 理由 |
|------|------|
| 自研回测而非调 Backtrader | 完全掌控成本模型与调仓时点，确保无前视偏差（look-ahead bias） |
| 用截面 rank 而非 z-score | 金融数据重尾，rank 对离群值稳健，且多因子加权时量纲统一 |
| 真实数据失败降级合成数据 | 弱网环境下保证 pipeline 可运行；合成数据注入可解释的因子结构，便于验证逻辑正确性 |
| 价格缺失绝不 fillna(0) | 价格置零会让 pct_change 产出 -100%/inf，污染整个回测 |
| 因子 shift(1) 后再算 IC | 用 t-1 日因子预测 t 日收益，避免用当天数据预测当天的前视偏差 |
| IC 为负的因子降权而非删除 | 保留观察窗口，市场风格切换后反向因子可能重新有效 |

## 数据说明

- **优先**：`yfinance` 拉取真实 A 股/港股日线（需要可访问 Yahoo Finance 的网络）
- **降级**：网络受限时自动生成带因子结构的合成数据（GBM + 截面动量 + 低波动异象 + 趋势持续性差异），保证回测流程可完整运行
- **注意**：合成数据上回测结果仅用于验证框架逻辑，不代表真实市场收益

## 面试讲述主线（60 秒版本）

> "我做了一个多因子选股回测系统。数据层做了真实数据优先、失败降级合成数据的容错设计；因子层实现了动量、低波动、反转三个经典因子，用逐日 IC 分析验证有效性，发现反转因子 IC 为负，就在合成时降权处理；回测引擎是自己写的向量化实现，每 20 日调仓、扣 0.1% 单边成本，特意用 shift(1) 避免前视偏差。最终策略夏普 1.59、最大回撤 12%，相对等权基准超额 14 个点。过程中还修了几个典型 bug：价格 fillna(0) 导致收益爆炸、基准净值被双重复利——这些坑让我对回测的正确性有了更实的理解。"
